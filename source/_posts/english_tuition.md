*Note: For my student, I am not disclosing his/her profile, as he/she is a public figure.*

## What I'm doing for work
I was using Python last week to make the quotation job easier for travel agencies.  
There were problems in my agency, where these quotations take too long to make as there were too many manual fields to fill in, with manual formula as well.  
As I recognised these patterns, I realised that it might be better to implement a Streamlit application where it would be like filling up a form.

### Benefit of using Streamlit and Python
Basically, you can use **Google Sheets** as the database. Afterwards, you save and load from this database whichever ones you need to continue with the procedure to get the final costs for your clients.  
This is really beneficial for DMCs (Destination Management Companies) like mine, because they're not so big or they might not even need ERP systems, but they can simply use this open source software to create quotations for their end clients.  
In this way, the final cost calculation becomes much more convenient and efficient - it can save up lots of time and bring less confusion, just with the "Save & Load" function, rather than duplicating sheet.

### Prepare mutliple (Google/Excel) sheets
Rather than using just one single CSV file, it is better to use multi-dimensional DB (in this case, it's not) that any office user would be able to understand.  
For this I realised that using a DB from Google Sheets or Excel sheet would be a good idea.
Otherwise, we will fail to have a single source of truth, and it'll bring confusion across the team.
